- Нет внешнего сигнала об аварии сборщика: `health.sh` запускается вручную и изнутри сервера.
- На сервере 22 `.tmp` без footer'а (06.11 18Z, 08.11 03Z): не удалять — данные 06.11 18:00–18:56 можно попытаться восстановить.

- Хвосты ревью 2.5 (описание PR #61): нет паузы между повторами чтения расписания; доля в логе включает позиции без дескриптора; чтение во время очистки импорта может оставить старый снимок на сутки; тест-защита `MATERIALIZED`.
- Нестабильный тест: 1 падение на 10 прогонов, название не сохранилось — при повторе issue.
- `PublishAot` выключает EventSource: `dotnet-counters` не видит Ingestor без `EventSourceSupport=true`.
- Нет расписаний HSL до 20.10 и Entur до 21.10; сбор 21.10 10:24–19:15 UTC отсутствует.
- В Processor до 2.10 нет снапшота и DLQ: после рестарта треки строятся заново.
- `health.sh`: фид живой при одной записи за час; WARN памяти внутри обычной пилы `anon`. Импорт GTFS в 5–7 раз медленнее проверки — не измерено (этап 8). Простой CPU сервера 06.11 09–17Z не разобран.
