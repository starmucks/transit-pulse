## Известные проблемы
- Нет внешнего сигнала об аварии сборщика: `health.sh` запускается вручную и изнутри сервера; при падении сервера молчит.
- На сервере 22 `.tmp` без footer'а (06.11 18Z, 08.11 03Z): `--repair` их не читает, `health.sh` FAIL `orphans`. Не удалять — данные 06.11 18:00–18:56 можно попытаться восстановить.
- Хвосты ревью 2.5 (в описании PR #61): нет паузы между повторами неудачного чтения расписания; доля в логе прогресса включает позиции без дескриптора; чтение во время очистки импорта может оставить старый снимок на сутки; тест-защита `MATERIALIZED` через `EXPLAIN`.
- Нестабильный тест: 1 падение на 10 полных прогонов, название не сохранилось. Хранить полный вывод, при повторе — issue.
- `health.sh`: фид считается живым при одной записи за час; WARN памяти (60 %) лежит внутри обычной пилы `anon`.
- `PublishAot` выключает EventSource: `dotnet-counters` не видит процесс без `EventSourceSupport=true`.
- Нет расписаний HSL до 20.10 и Entur до 21.10; сбор 21.10 10:24–19:15 UTC отсутствует (переезд).
- Импорт GTFS в 5–7 раз медленнее проверки — куда уходит время, не измерено (этап 8).
- В Processor до 2.10 нет снапшота и DLQ: после рестарта треки строятся заново, битые сообщения только считаются.
