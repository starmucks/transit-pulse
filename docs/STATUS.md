## Сборщик: потери HSL 13.11 — причина и обход
- С 11:40 UTC брокер рвал единственное `vp`-соединение каждые 40–180 с; в архиве 60–77 % дневного потока.
- Причина (замер): потери пакетов в сети хостера до VM — ping 3–14 % до HSL, 1.1.1.1, 8.8.8.8; 3,4 % TCP-сегментов не по порядку; RecvQ ≈ 0, vNIC без потерь. Одно TCP-соединение на потерях тянет 280–650 кБ/с при потоке ~600 кБ/с → брокер отключает медленного клиента.
- Обход: 4 соединения (автобусы / прочие × направление 1 / 2). Тест 15:48–15:53: сервер 425 792 против 424 699 у ПК, 0 обрывов. Деление по видам не годится: трамваи молчат ночью до 61 мин.

## Известные проблемы
- Сеть хостера теряет пакеты (обойдено для сборщика, не устранено); хостер отвечает неохотно.
- Хук перед коммитом проверяет `$CLAUDE_PROJECT_DIR`, а не git worktree, где идёт коммит.
- До 2.10 у Processor нет снапшота: рестарт обнуляет детекторы; нет DLQ.
- До route-keyed repartitioning (ADR-0013) несколько экземпляров Processor недосчитывают пары между процессами.
- Привязка (ADR-0011): улица в обе стороны — проходы мигают; скачок 30–100 м вперёд даёт откат; поезда 10 % вне маршрута.
